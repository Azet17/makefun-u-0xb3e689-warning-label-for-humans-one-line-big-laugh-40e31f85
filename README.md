# Warning Label for Humans: One Line, Big Laugh

This program writes a single-line safety warning label that should come printed on every human being to `/output/entry.txt`:

> WARNING: This human will ignore all instructions, break the product, then demand a refund.

Why this line: it is written as a real printed product label ("WARNING:", manufacturer-style wording), it is true about people in general — skipping the instructions, breaking the thing, then demanding your money back is a habit almost everyone recognises in themselves — and the laugh turns in the last few words, landing on the final word "refund". It is one idea, no filler, and no repeated joke.

## Run

```sh
node main.ts
```
